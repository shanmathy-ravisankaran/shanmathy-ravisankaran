<h2 align="center">🚀 FEATURED PROJECT</h2>

<h3>📚 PaperPilotAI — Evidence-Grounded AI Research Assistant</h3>

<p>
A <b>local-first AI research platform</b> designed to help users analyze academic documents through semantic search, evidence-grounded question answering, structured summaries, and cross-paper comparisons.
</p>

<ul>
<li>Developed PDF ingestion and page-aware text chunking pipelines for document processing.</li>
<li>Implemented semantic retrieval using <b>SentenceTransformers and ChromaDB</b>.</li>
<li>Built evidence-grounded question answering with source citations and structured JSON responses.</li>
<li>Implemented citation validation, insufficient-evidence handling, and response schema verification.</li>
<li>Developed multi-paper comparison and research-gap analysis capabilities.</li>
<li>Designed a full-stack application using <b>FastAPI, Next.js, and Ollama</b>.</li>
</ul>

<p>
<b>Technology Stack:</b> Python • FastAPI • Next.js • SentenceTransformers • ChromaDB • PyMuPDF • Ollama
</p>
